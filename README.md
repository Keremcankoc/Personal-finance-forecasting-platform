A modular desktop application designed for personal financial management, recursive budgeting simulations, and predictive cash-flow forecasting backed by relational database architecture.

## 🚀 Key Features

- **Predictive Forecasting Engine:** Simulates future net worth and cash flow trends based on recurring transactions and expense habits.
- **Automated Alerts:** Rule-based engine monitoring budget exceedances and unusual account activities.
- **Relational Data Modeling:** Normalized database schema supporting multi-account structures and complex transactional queries.
- **Role-Based GUI:** Dedicated interfaces for end-users and administrative controls.

## 🏗️ Architecture

- **Presentation Layer:** Python GUI (Desktop Views)
- **Service Layer:** `forecast_engine.py`, `alert_engine.py`
- **Data Access Layer:** Typed domain models (`models/`)
- **Database:** Relational SQL schema (`schema.sql`, `queries/advanced_queries.sql`)
